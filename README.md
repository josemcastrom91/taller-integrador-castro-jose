Defecto	Por qué es un problema
1	Nombres de archivo Mi Pagina De Notas.HTML y Estilos Del Sitio.CSS	Tienen espacios, mayúsculas y tildes; rompe convenciones y puede dar problemas en distintos sistemas operativos
2	Título de la pestaña: <title>pagina</title>	No describe el contenido del sitio
3	Variables a, b, c en calc()	No indican qué almacenan (las notas)
4	Variable x = 3	"Número mágico" sin nombre que explique qué representa
5	Variable TempValue2	Nombre sin sentido, no describe que es el promedio
6	Variable data1 = []	Se declara y nunca se usa en ningún lado
7	Función calc()	Nombre demasiado corto, no describe la acción (calcular promedio)
8	IDs n1, n2, n3, r, r2	No son descriptivos, obligan a adivinar qué contiene cada elemento
9	console.log(...) de depuración (3 líneas) y función comentada calcularAntiguo	Código muerto / de prueba que no debe quedar en producción
